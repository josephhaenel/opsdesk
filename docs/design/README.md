# Casework asset notes

The wordmark and favicon are generated raster assets based on the selected Casework design. They use transparent PNGs and are not reconstructed with SVG or CSS.

The interface fonts are self-hosted Inter and Libre Caslon Display from the official Google Fonts repository. Their original SIL Open Font License files accompany the font files in `apps/web/public/fonts/`. Interface icons use Lucide React.

The project remains at its existing OpsDesk address and repository. Internal database, package, and browser-storage names stay stable so the rebrand does not reset visitor sessions.
